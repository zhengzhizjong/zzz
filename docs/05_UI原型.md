## 六、交互规范

### 6.1 预约相关交互规范

| 场景 | 交互规范 | 视觉表现 |
|------|----------|----------|
| 已占用时段 | 不可选择，显示🔒图标+文字"已约" | 灰色背景(#F0F0F0) + 🔒图标 + "已约"文字 + 禁止点击态 |
| 可选时段 | 可点击选择，选中后高亮 | 绿色背景(#07C160) + 白色文字 |
| 不指定技师 | 默认选中态，选中后跳过技师选择直接进入时间选择 | 顶部选项卡，选中态:绿色边框+✅图标，未选中态:白色背景 |
| 预约锁档 | 选定时段后5分钟内完成确认，超时自动释放时段 | 顶部倒计时提示(⏱️ mm:ss) + 确认页倒计时 + 超时弹窗提醒"时段已释放，请重新选择" |
| 修改预约 | 弹窗选择新时间/新技师，确认后原时段释放 | 底部弹窗 + 原时段释放提示(⚠️) + 二次确认按钮 |
| 取消预约 | 弹窗填写取消原因(必填)，确认后时段释放 | 底部弹窗 + 取消原因单选 + 其他原因输入框 + ⚠️时段释放提示 + 二次确认按钮 |
| 修改/取消确认弹窗 | 二次确认防误操作 | 弹窗双按钮(取消/确认) + 确认按钮使用警示色(#FA5151) |

### 6.2 预约锁档机制

```
选时段 → 锁定5分钟 → 倒计时显示 → 超时处理
   │           │            │            │
   ▼           ▼            ▼            ▼
 时段标记    其他用户      剩余<1分钟    弹窗提醒
 为"锁定中"  不可选该时段   红色倒计时    "时段已释放
                                      请重新选择"
```

> **锁档规则**：
> - 用户选定时段后，该时段对其他用户标记为"锁定中"(灰色+🔒)
> - 锁定时长5分钟，倒计时在Step3底部和Step4顶部同步显示
> - 倒计时<1分钟时变为红色警示
> - 超时未确认，自动释放时段，弹窗提示用户重新选择
> - 确认预约成功后，时段状态变为"已约"
