#### 1.2.2 Step 1 选门店

**页面元素：**

| 元素 | 规格 | 数据来源 |
|------|------|----------|
| 定位提示 | "📍 当前定位: {商圈名}"，14px，灰色 | 系统定位 |
| 门店卡片列表 | 纵向滚动，每张卡片全宽，圆角12px，白色背景 | 门店API |
| 门店名 | 16px加粗，左侧 | store_name |
| 距离 | 14px，右侧，如"800m" | 距离计算 |
| 评分 | "★{评分}"，14px，如"★4.9" | avg_rating |
| 营业状态标签 | 绿色圆点+"营业中" / 红色圆点+"已打烊"，12px | business_status |
| 技师数 | "{n}名技师"，12px，灰色 | technician_count |
| 服务次数 | "已服务{n}次"，12px，灰色 | service_count |

**交互：**

| 交互 | 行为 |
|------|------|
| 点击门店卡片 | 选中该门店，卡片边框变为2px绿色(#07C160)，其他卡片恢复默认1px灰色边框 |
| 点击"下一步"按钮 | 校验是否已选门店，已选→进入Step2，未选→Toast"请选择门店" |
| 下拉刷新 | 刷新门店列表和距离 |

**校验规则：**

| 规则 | 说明 |
|------|------|
| 必填 | 是，必须选择一个门店 |
| 排序 | 默认按距离升序，支持按评分/距离切换 |
| 过滤 | 已打烊门店灰色展示，可点击但提示"该门店已打烊，明日{营业时间}营业" |

**空状态：**

| 场景 | 表现 |
|------|------|
| 无门店数据 | zjt-empty组件，文案"暂无门店信息" |
| 定位失败 | 提示"定位失败，请检查定位权限"，仍可手动搜索门店 |

**"下一步"按钮：**

| 属性 | 值 |
|------|------|
| 位置 | 页面底部固定，全宽，高度48px |
| 文案 | "下一步：选技师 →" |
| 颜色 | 未选门店：灰色(#CCCCCC)不可点击；已选门店：绿色(#07C160)可点击 |

**交互：**

| 交互 | 行为 |
|------|------|
| 点击"不指定技师" | 选中，选项卡变为绿色边框+✅图标，技师卡片取消选中 |
| 点击技师卡片 | 选中该技师，卡片边框变2px绿色，"不指定技师"取消选中✅ |
| 点击已约满技师 | 不可选中，Toast"该技师今日已约满" |

**校验规则：**

| 规则 | 说明 |
|------|------|
| 必填 | 否，默认选中"不指定技师" |
| 不指定技师时 | 跳过技师选择，系统自动派单（空闲+技能匹配+轮询） |
| 已约满技师 | 灰色+文字"约满"，不可点击选中 |

**"下一步"按钮：**

| 属性 | 值 |
|------|------|
| 文案 | "下一步：选时间 →" |
| 颜色 | 绿色(#07C160)可点击（此步无必填校验） |

#### 1.2.4 Step 3 选日期+时间

**日期选择：**

| 元素 | 规格 | 说明 |
|------|------|------|
| 月份切换 | "2026年6月"，左右箭头切换月份 | - |
| 日历网格 | 7列(日一二三四五六)，行数随月份 | zjt-calendar组件 |

| 可选范围 | 今天及之后7天 | 超出范围灰色不可选 |

**时段网格：**

| 元素 | 规格 | 说明 |
|------|------|------|
| 时段标题 | "{月}月{日}日(周{几}) 可选时段："，14px | - |
| 时段按钮网格 | 每行3-4个时段按钮 | - |
| 可选时段 | 绿色背景(#E8F8EE)+绿色文字(#07C160)，点击选中变深绿背景(#07C160)+白色文字 | - |
| 已占用时段 | 灰色背景(#F0F0F0)+🔒图标+"已约"文字(#999999)，不可点击 | - |
| 已约满整行 | 整行时段灰色，不可点击 | - |
| 选中时段 | 深绿背景(#07C160)+白色文字+对勾图标 | - |

**交互：**

| 交互 | 行为 |
|------|------|
| 点击可选日期 | 切换日期，刷新该日时段列表 |
| 点击历史日期 | 无响应，不可选 |
| 点击可选时段 | 选中该时段，其他时段取消选中，触发5分钟锁档倒计时 |
| 点击已占用时段 | 无响应，不可选 |
| 选中时段后 | 底部显示提示"⏱️ 请在5分钟内完成预约" |
| 点击"下一步"按钮 | 校验是否已选日期+时段，已选→进入Step4，未选→Toast"请选择日期和时段" |

**校验规则：**

| 规则 | 说明 |
|------|------|
| 必填 | 日期+时段均为必填 |
| 时段实时刷新 | 时段状态实时刷新延迟≤3s |
| 锁档 | 选中时段后5分钟内完成确认，超时自动释放 |

**锁档提示：**

| 位置 | 文案 | 样式 |
|------|------|------|
| Step3底部 | "⏱️ 选定时段后5分钟内完成确认，超时将自动释放" | 14px，橙色(#FF9D00) |
| 选中时段后底部 | "⏱️ 请在5分钟内完成预约" | 14px，橙色(#FF9D00)，倒计时mm:ss |

**"下一步"按钮：**

| 属性 | 值 |
|------|------|
| 文案 | "下一步：确认预约 →" |
| 颜色 | 未选日期+时段：灰色(#CCCCCC)不可点击；已选：绿色(#07C160)可点击 |

#### 1.2.5 Step 4 确认预约

**预约摘要卡片：**

| 字段 | 标签 | 值 | 必填标注 | 说明 |
|------|------|------|----------|------|
| 门店 | "门店 *" | {门店名} | 红色*号 | 必填 |
| 技师 | "技师" | {技师名}或"不指定(系统分配)" | 无 | 非必填 |
| 日期 | "日期 *" | {年}年{月}月{日}日 周{几} | 红色*号 | 必填 |
| 时段 | "时段 *" | {开始时间} - {结束时间} | 红色*号 | 必填 |
| 项目 | "项目 *" | {项目名}({时长}分钟) | 红色*号 | 必填 |

**倒计时：**

| 属性 | 值 |
|------|------|
| 位置 | 摘要卡片下方 |
| 文案 | "⏱️ 请在 {mm:ss} 内完成确认" |
| 样式 | 16px，正常态黑色，<1分钟红色(#FA5151) |
| 超时处理 | 弹窗提示"预约超时，请重新选择时段"，点击确定→回到Step3 |

**"确认预约"按钮：**

| 属性 | 值 |
|------|------|
| 位置 | 页面底部固定，全宽，高度48px |
| 文案 | "确认预约" |
| 颜色 | 缺少必填项：灰色(#CCCCCC)不可点击；信息完整：绿色(#07C160)可点击 |
| 点击后 | 调用预约提交API，成功→跳转"我的预约"页+Toast"预约成功"；失败→Toast错误信息 |

**确认后行为：**

| 步骤 | 行为 |
|------|------|
| 1 | 跳转到"我的预约"页面，定位到"待服务"Tab |
| 2 | Toast提示"预约成功"，持续2s |
| 3 | 如指定技师，系统推送通知给技师 |
| 4 | 如"不指定技师"，系统自动派单并通知技师 |

## 四、异常场景处理规则

| # | 场景 | 触发条件 | 处理方式 | 提示文案 | UI表现 |
|---|------|----------|----------|----------|--------|
| 1 | 时段约满 | 时段已被预约/锁定 | 灰色不可选 | "该时段已约满" | 灰色背景+🔒图标+"已约"文字，不可点击 |
| 2 | 历史日期 | 选择今天之前的日期 | 灰色禁用 | 不可点击，无Toast | 历史日期灰色文字，不可点击 |
| 3 | 重复预约 | 同一客户+同一门店+同一时段已有预约 | 拦截提交 | "您已有该时段的预约" | Toast提示，提交按钮置灰 |
| 4 | 过期锁定 | 选时段后5分钟未确认 | 自动释放时段 | "预约超时，请重新选择时段" | 弹窗提示，点击确定→回到Step3 |
| 5 | 过期预约不可改 | 预约时间已过 | 隐藏修改/取消按钮 | - | 修改按钮和取消按钮均不显示 |
