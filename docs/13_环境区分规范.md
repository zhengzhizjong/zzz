# 忠济堂中医养生连锁管理系统 · 环境区分规范（V3.4）

## 一、环境定义

| 环境 | 用途 | 数据库 | 域名 | 分支 |
|------|------|--------|------|------|
| dev | 开发调试 | 开发库(可删重建) | dev-api.zhongjitang.com | feature/* |
| test | 测试验证 | 测试库(模拟生产) | test-api.zhongjitang.com | develop |
| prod | 生产环境 | 生产库(真实数据) | api.zhongjitang.com | main |

## 三、密钥管理规范

| 规则 | 说明 |
|------|------|
| 禁止硬编码 | 密钥不可写入代码，必须通过环境变量注入 |
| 禁止提交 | .env文件加入.gitignore，禁止提交到仓库 |
| 密钥轮换 | 生产密钥每90天轮换一次 |
| 最小权限 | 每个环境使用独立的数据库账号和API Key |
| 审计日志 | 密钥使用记录可追溯 |

## 四、数据隔离规范

| 规则 | dev | test | prod |
|------|-----|------|------|
| 数据库 | 独立库，可随意操作 | 独立库，模拟生产数据 | 独立库，真实数据 |
| Redis | 独立实例 | 独立实例 | 独立集群 |
| OSS | 独立桶 | 独立桶 | 独立桶 |
| 微信 | 测试号 | 体验版 | 正式版 |

## 五、环境切换规范

| 操作 | 规则 |
|------|------|
| 开发→测试 | 合并feature到develop，自动部署到test |
| 测试→生产 | 创建release分支，测试通过后合并到main，自动部署到prod |
| 紧急修复 | 从main拉hotfix，修复后合并到main+develop |
| 数据库变更 | 必须提供增量SQL和回滚SQL，三个环境依次执行 |
