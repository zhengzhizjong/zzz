## 一、项目概述

### 1.1 项目背景

忠济堂中医养生连锁管理系统是一个面向中医养生连锁集团的全栈数字化运营平台。随着连锁规模扩大（目标万店级），传统单体系统面临性能瓶颈、数据孤岛、AI能力分散、无法多品牌运营等挑战。V3.4版本在V3.3基础上，重构了客户预约全流程、新增技师推广模块、建立全链路数据统计体系，确保每个需求可量化、可验证、可零返工交付。

### 1.2 项目目标

| 目标维度 | 具体指标 |
|----------|----------|
| **业务目标** | 支持万店级连锁运营，实现"一个系统完成所有事" |
| **技术目标** | DDD六域微服务架构，CQRS读写分离，支持百万级DAU |
| **商业目标** | SaaS可租可售，多租户计费体系，多品牌白标支持 |
| **AI目标** | AI全链路嵌入（问诊/话术/日报/营销/推荐），LLM统一网关调度 |
| **数据目标** | 预约/推广全链路埋点，漏斗分析可量化，数据驱动决策 |

#### 2.4.3 预约状态机

```
待到店 ──(到店核销)──→ 已完成
  │
  ├──(修改时间/技师)──→ 待到店（新时段）
  │
  └──(取消，填写原因)──→ 已取消（时段释放）
```

- **待到店**：预约成功后的初始状态，可修改/可取消
- **已完成**：到店核销后的终态，不可变更
- **已取消**：客户主动取消后的终态，时段已释放，不可恢复
