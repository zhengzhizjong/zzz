## 一、数据库设计规范

### 1.1 命名规范

| 规范项 | 标准 | 示例 |
|--------|------|------|
| 数据库名 | {domain}_db | trade_db, user_db |
| 表名 | {domain}_{entity} | store_room, trade_order |
| 字段名 | snake_case | created_at, member_id |
| 主键 | id BIGINT | id BIGINT PRIMARY KEY |
| 索引名 | idx_{table}_{columns} | idx_trade_order_member |
| 外键 | 应用层保证，不建数据库约束 | - |
| 金额字段 | DECIMAL(10,2) | amount DECIMAL(10,2) |
| 状态字段 | TINYINT + 字典表 | status TINYINT |
| 多租户 | tenant_id BIGINT NOT NULL | - |
| 门店隔离 | store_id BIGINT | - |
| 审计字段 | created_at/updated_at/created_by/updated_by/is_deleted | - |

### 1.2 必须字段（所有表）

```sql
-- 强制字段规范（所有业务表必须包含）
CREATE TABLE template_table (
    id              BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键',
    tenant_id       BIGINT      NOT NULL COMMENT '租户ID',
    store_id        BIGINT COMMENT '门店ID',

    -- 审计字段
    created_at      DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at      DATETIME    NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    created_by      VARCHAR(64) COMMENT '创建人',
    updated_by      VARCHAR(64) COMMENT '更新人',
    is_deleted      TINYINT     NOT NULL DEFAULT 0 COMMENT '软删除:0正常,1删除',

    -- 索引
    INDEX idx_tenant_id (tenant_id),
    INDEX idx_store_id (store_id),
    INDEX idx_created_at (created_at)
);
```

## 三、核心表DDL

### 3.1 会员表（user_member）

```sql
CREATE TABLE user_member (
    id                  BIGINT PRIMARY KEY AUTO_INCREMENT,
    tenant_id           BIGINT NOT NULL COMMENT '租户ID',
    store_id            BIGINT COMMENT '归属门店ID',

    -- 基本信息
    member_no           VARCHAR(32) COMMENT '会员编号(自动生成)',
    name                VARCHAR(64) NOT NULL COMMENT '姓名',
    phone               VARCHAR(20) NOT NULL COMMENT '手机号',
    gender              TINYINT COMMENT '性别:0女,1男,2未知',
    birthday            DATE COMMENT '生日',
    avatar              VARCHAR(512) COMMENT '头像',

    -- 健康信息
    constitution_type   TINYINT COMMENT '体质类型:1-9(平和/气虚/阳虚/阴虚/痰湿/湿热/血瘀/气郁/特禀)',
    constitution_score  DECIMAL(5,2) COMMENT '体质评分',
    constitution_time   DATETIME COMMENT '辨识时间',

    -- 会员等级
    member_level_id     BIGINT COMMENT '等级ID',
    member_type         TINYINT NOT NULL DEFAULT 1 COMMENT '会员类型:1散客,2会员,3VIP',

    -- 账户
    points              INT NOT NULL DEFAULT 0 COMMENT '积分余额',
    balance             DECIMAL(10,2) NOT NULL DEFAULT 0.00 COMMENT '储值余额',

    -- 来源
    source_channel      VARCHAR(32) COMMENT '来源渠道:miniprogram/wechat_work/douyin/meituan/xiaohongshu',
    referrer_id         BIGINT COMMENT '推荐人ID',

    -- 状态
    status              TINYINT NOT NULL DEFAULT 1 COMMENT '状态:1正常,2冻结,3注销',
    last_visit_time     DATETIME COMMENT '最近到店时间',
    visit_count         INT NOT NULL DEFAULT 0 COMMENT '到店次数',

    -- 审计
    created_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at          DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    created_by          VARCHAR(64),
    updated_by          VARCHAR(64),
    is_deleted          TINYINT NOT NULL DEFAULT 0,

    INDEX idx_tenant (tenant_id),
    INDEX idx_phone (phone),
    INDEX idx_member_no (member_no),
    INDEX idx_constitution (constitution_type),
    INDEX idx_store_status (store_id, status)
) COMMENT '会员表';
```
