// I{Entity}Service.java
public interface IEntityService {
    PageResult<EntityResponse> pageEntities(EntityQuery query);
    EntityDetailResponse getEntityDetail(Long id);
    EntityResponse createEntity(EntityCreateRequest request);
    void updateEntity(Long id, EntityUpdateRequest request);
    void changeStatus(Long id, Integer status);
}

// {Entity}ServiceImpl.java
@Service
@RequiredArgsConstructor
@Slf4j
@Transactional(rollbackFor = Exception.class)
public class EntityServiceImpl implements IEntityService {

    private final EntityMapper entityMapper;

    @Override
    public PageResult<EntityResponse> pageEntities(EntityQuery query) {
        Long tenantId = TenantContext.getTenantId();
        Page<EntityDO> page = new Page<>(query.getPage(), query.getPageSize());
        LambdaQueryWrapper<EntityDO> wrapper = new LambdaQueryWrapper<>();
        wrapper.eq(EntityDO::getTenantId, tenantId);
        if (query.getStatus() != null) {
            wrapper.eq(EntityDO::getStatus, query.getStatus());
        }
        if (StringUtils.hasText(query.getKeyword())) {
            wrapper.and(w -> w.like(EntityDO::getName, query.getKeyword())
                    .or().like(EntityDO::getPhone, query.getKeyword()));
        }
        wrapper.orderByDesc(EntityDO::getCreatedAt);
        Page<EntityDO> result = entityMapper.selectPage(page, wrapper);
        return PageResult.of(result, EntityResponse.class);
    }
}
```

## 十、预约流程开发Prompt

### 10.1 预约创建Prompt

```
你是一名Java后端工程师。请为忠济堂V3.3养生管理系统生成预约创建Service代码。

上下文：
- 框架：Spring Boot 2.7 + MyBatis Plus
- 规范：多租户(tenant_id)、统一响应R<T>、全局异常处理
- 代码路径：com.zhongjitang.appointment.service

需求：生成预约创建逻辑，包含以下关键步骤：

1. 防重复提交校验
   - 使用 @RepeatSubmit 注解拦截重复请求
   - 同一用户3秒内不可重复提交

2. 预约锁档（Redis分布式锁）
   - 选择时段后先锁定，Redis SETNX + 5分钟TTL
   - 锁定key格式：appointment:lock:{storeId}:{timeSlot}
   - 锁定失败返回"时段已被占用"

3. 必填校验
   - 门店ID(storeId)：必填
   - 服务项目ID(serviceItemId)：必填
   - 预约时间(startTime)：必填，不能早于当前时间+2小时
   - 技师ID(technicianId)：可选，不选则系统分配

4. 创建流程
   - 校验时段可用 → 锁定时段 → 创建预约记录(status=1待确认) → 发布预约创建事件

5. 事件发布
   - 通过RocketMQ发布 AppointmentCreatedEvent
   - 下游消费：通知技师、发送客户确认短信

要求：
- 使用乐观锁(version)防止并发冲突
- 所有写操作加 @Transactional
- 日志使用 [预约创建] 前缀
- 异常使用 AppointmentException + 错误码枚举
```

### 10.2 预约修改Prompt

```
你是一名Java后端工程师。请为忠济堂V3.3养生管理系统生成预约修改Service代码。

上下文：
- 框架：Spring Boot 2.7 + MyBatis Plus
- 规范：多租户(tenant_id)、乐观锁(version)、事件驱动

需求：生成预约修改逻辑，包含以下关键步骤：

1. 时段释放与重新锁定
   - 校验新时段可用 → 锁定新时段(Redis SETNX + 5分钟TTL)
   - 释放旧时段(Lua脚本原子删除)
   - 旧时段释放和新时段锁定必须在同一事务中

2. 乐观锁version校验
   - 更新时 WHERE version = expectedVersion
   - 更新失败抛出 AppointmentException(VERSION_CONFLICT)
   - 更新成功 version + 1

3. 修改规则
   - 仅"已确认"状态的预约可修改
   - 新时段必须可用，否则修改失败
   - 修改成功后状态保持"已确认"，version+1

4. 通知技师
   - 发布 AppointmentModifiedEvent
   - 包含旧时段和新时段信息

5. 异常回滚
   - 修改失败时释放新时段锁
   - 旧时段锁保持不变

要求：
- 使用 AppointmentModifyService 类名
- 注入 AppointmentLockService 和 EventPublisher
- 日志使用 [修改预约] 前缀
```

5. 返回格式
   - JSON：{steps: [{name, count, rate}], rankings: [...], period, storeId}

要求：
- 推广追踪数据从ClickHouse查询
- 佣金数据从MySQL查询
