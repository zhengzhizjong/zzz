## 三、详细开发任务

### P0 - 核心缺失（必须完成才能上线）

#### 任务1：用户认证与会员模块（zjt-user）

**涉及表**：user_member, user_member_account, user_member_level, user_employee, user_role, user_permission, user_role_permission

**后端开发**：
1. 创建zjt-user模块（pom.xml + 模块结构）
2. UserMemberDO + Mapper + Service + Controller
   - POST /api/v1/user/members/register - 会员注册（手机号+验证码）
   - POST /api/v1/user/members/login - 会员登录（手机号+验证码/微信授权）
   - GET /api/v1/user/members/profile - 获取个人信息
   - PUT /api/v1/user/members/profile - 更新个人信息
   - POST /api/v1/user/members/wechat-bind - 微信绑定
   - POST /api/v1/user/members/wechat-login - 微信登录
3. UserMemberAccountDO + Mapper + Service
   - 微信openid/unionid管理
   - 手机号绑定/换绑
4. UserMemberLevelDO + Mapper + Service
   - GET /api/v1/user/member-levels - 等级列表
   - 自动升级规则（消费金额/次数达标自动升级）
5. UserEmployeeDO + Mapper + Service + Controller
   - POST /api/v1/user/employees/login - 员工登录
   - GET /api/v1/user/employees - 员工列表
   - POST /api/v1/user/employees - 创建员工
   - PUT /api/v1/user/employees/{id} - 更新员工
6. UserRoleDO + UserPermissionDO + UserRolePermissionDO
   - RBAC权限管理
   - GET /api/v1/user/roles - 角色列表
   - POST /api/v1/user/roles - 创建角色
   - PUT /api/v1/user/roles/{id}/permissions - 分配权限
   - GET /api/v1/user/permissions - 权限树
7. 短信验证码服务（集成腾讯云SMS）
   - POST /api/v1/user/sms/send - 发送验证码
   - 验证码5分钟有效，60秒限流

**前端管理后台**：
- 员工管理页面（EmployeeList.vue + EmployeeForm.vue）
- 角色权限管理页面（RoleList.vue + PermissionTree.vue）
- 会员管理页面（MemberList.vue + MemberDetail.vue）

**客户端小程序**：
- 登录页面（手机号+验证码 / 微信一键登录）
- 个人信息编辑页面
- 会员等级展示

**技师端小程序**：
- 员工登录页面

#### 任务2：订单与支付模块

**涉及表**：trade_order, trade_order_item, trade_payment, trade_refund

**后端开发**（在zjt-trade模块中补充）：
1. TradeOrderDO已有，补充完整CRUD
   - POST /api/v1/trade/orders - 创建订单（预约确认后自动创建）
   - GET /api/v1/trade/orders - 订单列表
   - GET /api/v1/trade/orders/{id} - 订单详情
   - PUT /api/v1/trade/orders/{id}/complete - 完成服务
2. TradeOrderItemDO + Mapper + Service
   - 订单明细管理（一个订单可含多个服务项目）
3. TradePaymentDO + Mapper + Service + Controller
   - POST /api/v1/trade/payments/create - 创建支付单
   - POST /api/v1/trade/payments/wechat-notify - 微信支付回调
   - GET /api/v1/trade/payments/{id} - 支付详情
   - 微信支付对接（JSAPI/H5/Native）
4. TradeRefundDO + Mapper + Service + Controller
   - POST /api/v1/trade/refunds - 申请退款
   - POST /api/v1/trade/refunds/{id}/approve - 审批退款
   - POST /api/v1/trade/refunds/wechat-notify - 微信退款回调

**前端管理后台**：
- 订单管理页面（OrderList.vue）
- 退款管理页面（RefundList.vue）

**客户端小程序**：
- 订单支付页面
- 退款申请页面

## 六、验收标准

1. 每个SQL表必须有对应的DO类
2. 核心业务表必须有完整的Mapper/Service/Controller
3. 所有前端页面必须可访问、可交互
4. 所有小程序页面必须可导航、可操作
5. 用户认证流程完整可用（注册→登录→Token→鉴权）
6. 支付流程完整可用（下单→支付→回调→完成）
7. 单元测试覆盖核心业务逻辑
